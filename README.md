# Page Joyful

Invitations de mariage numériques.

## Taha et Yassmine

Invitation pour le mariage de **Taha & Yasmine** — samedi 17 octobre 2026, 11h00,
Salle des fêtes l'Alliance, Constantine.

Le dossier [`Taha et Yassmine/`](./Taha%20et%20Yassmine/) contient trois fichiers, sans
dépendance ni serveur : ouvrez `index.html` dans un navigateur.

| Fichier | Rôle |
| --- | --- |
| `index.html` | structure de la page |
| `styles.css` | mise en page, typographie, animations |
| `script.js` | configuration, décors végétaux, décompte |

### Modifier l'invitation

Tout se règle dans l'objet `invitation`, tout en haut de `script.js` :
noms, date, heure, lieu, lien Google Maps et textes. Les noms du jour et du mois
sont calculés automatiquement à partir de la date.
